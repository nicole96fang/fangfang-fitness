# 🥀努力减肥的肥芳

Mobile-first static fitness journal.

## Features
- Profile + automatic BMI
- Weight records + trend chart
- Daily progress photos stored in IndexedDB
- Water/drink records
- Exercise video pages + completion history
- Meal / fasting checklist templates
- Local persistence with localStorage + IndexedDB
- Snowfall animation
- No backend, no ads, no pop-up advertising

## GitHub Pages
Upload `index.html` to a repository, then enable **Settings → Pages → Deploy from branch → main / root**.

> Note: browser storage is device/browser-local. Clearing site data or switching devices will remove local records unless you add a cloud backup later.
